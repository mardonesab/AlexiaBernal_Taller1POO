# Taller 1 - Programacion Orientada a Objetos

## Descripcion

Programa en Java para controlar el ingreso de alumnos a un grupo de POO.

El programa permite cargar alumnos y solicitudes desde archivos, procesar las solicitudes, realizar inscripciones manuales, administrar los alumnos, generar reportes y mostrar estadisticas.

## Archivos

- Main.java
- Alumnos.txt
- Solicitudes.txt

## Como ejecutar

1. Abrir el proyecto en Eclipse.
2. Ejecutar Main.java.
3. Seleccionar la opcion 1 para cargar los archivos.
4. Utilizar las opciones del menu.

## Consideraciones

- El maximo es de 100 alumnos y 100 solicitudes.
- Los paralelos son C1 y C2.
- Los RUT se ingresan sin puntos y con guion.
- Los reportes se generan como archivos de texto.
